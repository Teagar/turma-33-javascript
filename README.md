# Turma 33 — JavaScript

Exercícios da aula de JavaScript e HTML, do básico aos fundamentos de funções.

## Como usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Teagar/turma-33-javascript.git
   ```

2. Entre na pasta de cada exercício (`exercicio-01` até `exercicio-08`).
3. Escreva o seu código no `app.js` (e no `index.html`, no exercício 01).
4. Rode a página com um servidor local, por exemplo a extensão **Live Server** do VS Code, e abra o console com **F12**.

## Ordem dos exercícios

| Pasta | Assunto |
|---|---|
| `exercicio-01` | HTML básico, ligação com `app.js`, `console.log`, `const`, template strings |
| `exercicio-02` | Strings: tamanho, índices, métodos de texto |
| `exercicio-03` | Arrays: adicionar, remover, juntar, procurar, matrizes |
| `exercicio-04` | Coerção, `typeof`, valores falsy, `===` e `==` |
| `exercicio-05` | Laços: `while`, `for`, laços aninhados |
| `exercicio-06` | Condicionais: `if`, `else`, operadores lógicos |
| `exercicio-07` | `switch`, `break`, `continue` |
| `exercicio-08` | Funções: declaração, expressão, parâmetros e `return` |

## Regras

- Não digite resultados manualmente quando o enunciado pedir para não fazer isso.
- Não apague os comentários dos enunciados. Comente o código de um exercício antes de começar o seguinte, se o enunciado pedir.
- Antes de pedir ajuda, leia a mensagem de erro no console e tente reproduzir o problema em uma linha isolada.
